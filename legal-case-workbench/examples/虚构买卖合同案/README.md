# 示例案件：甲公司诉乙公司买卖合同纠纷（全部虚构）

用来试跑 `legal-case-workbench`。当事人、案号、法院、金额均为虚构，不对应任何真实案件。

## 材料

| 批次 | 材料 |
|---|---|
| 第一批 | 民事起诉状、钢材买卖合同、对账单、传票 |
| 第二批 | 被告答辩状、一审判决书、判决书送达回证 |

材料里故意埋了几处要靠交叉比对才能发现的问题，可以用来检验事实核查员：

- 签约日：起诉状和合同写的不一样。
- 违约金起算日：起诉状、按合同条款推算、判决，三个日期各不相同。
- 4 月 15 日那笔 10 万元：对账单、起诉状没有反映，答辩状和判决有。
- 上诉期：要用送达回证上的日期起算，届满日恰逢周末。

## 怎么试

本示例放在技能文件夹里，随技能一起安装（例如 Claude Code 装在 `~/.claude/skills/legal-case-workbench/examples/`）。

**最简单**：以案件根目录为工作文件夹新开一个对话，对 agent 说“用案件分析工作台自带的示例案件试跑一下”。它会在根目录下建 `甲公司买卖合同纠纷案件_<日期>`，分两批入卷并汇报。还没有案件根目录的，它会先问你放在哪里。

**手动**（`<技能目录>` 指 `legal-case-workbench` 装在哪里）：

1. 建工作台：`python3 <技能目录>/scripts/init_case.py --root <案件根目录> --party 甲公司 --cause 买卖合同纠纷 --type 民事`，会建出 `<案件根目录>/甲公司买卖合同纠纷案件_<日期>/`
2. 把 `<技能目录>/examples/虚构买卖合同案/第一批/` 的文件复制进这个案件文件夹的 `材料/`，对 agent 说“新材料到了”。
3. 看它的回报和各表，再复制 `第二批/`，说“新材料到了”。
4. 看第二批入卷后，旧问题有没有被正确标为“已结”或更新，上诉期是否按送达回证推算。

案件根目录不要设在技能目录里面，免得把试跑产生的文件混进技能。
